Homelab

Overview

Building and maintaining a comprehensive homelab environment for learning, testing, and development. This setup includes virtualization, containerization, storage solutions, and various services for hands-on experience with enterprise-level technologies.

Infrastructure

• Proxmox and VMware virtualization
• Docker and Kubernetes containers
• TrueNAS storage systems
• Linux servers (Ubuntu, Debian, CentOS)
• NVIDIA Jetson edge computing devices

Services & Applications

Self-hosted services including media servers, automation tools, monitoring solutions, and development environments. The homelab serves as a testing ground for new technologies and a platform for continuous learning in IT infrastructure and system administration.
